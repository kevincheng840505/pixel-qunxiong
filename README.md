# 群雄誌

網頁版水墨風三國群雄策略遊戲（試玩版 v0.5）。手機與電腦瀏覽器都能玩，不需安裝。

**立即遊玩：** https://kevincheng840505.github.io/pixel-qunxiong/

## 遊戲內容

- **劇本**：西元 190 年・群雄討董，8 路諸侯（全部可選）、114 位武將
- **大地圖**：44 座城池、9 處關卡、10 座港口，以陸路與水路相連；可拖曳、滾輪或雙指縮放
- **月回合**：一個月一回合，用「軍令」在內政、出陣、外交之間取捨；九月秋收
- **行軍**：武將帶兵出陣成為地圖上的部隊，指定目的地後每月沿道路前進，港口之間可走水路；攜帶糧草，可改道、停下、撤回；電腦勢力遵守同樣規則
- **活的地圖**（v0.5）：每支部隊的行軍路線以發光流動線畫在地圖上，部隊平滑移動、旗幟飄動、雲霧飄過，春夏秋冬各有落花、螢火、落葉、飛雪；交戰處留下戰火標記
- **軍情看板**：地圖左上列出天下所有部隊（出陣／行軍／渡江／進攻／來犯／回師／駐留、預計月數、兵力），上方是各勢力版圖比例；地圖下方時間軸標出本月進度、各月戰事數、秋收與停戰期滿，點月份可看當月大事
- **跟拍與晝夜**：「跟拍」讓鏡頭跟著下一支即將交戰的部隊；☾ 切換夜晚，城郭燈火與營火亮起；電腦上滑鼠停在據點或部隊上會顯示小卡
- **野戰與攻城**：敵我部隊途中相遇打野戰（水路上為水戰），抵達敵方或中立據點打攻城戰
- **內政**：開墾、商業、修城、徵兵、施政、訪賢（尋找在野人才）、賞賜
- **武將**：勇／謀／治／德四項屬性，加上天賦與性格，影響戰鬥、內政與登用
- **六角格攻城戰**：最多 5 將出征，槍／騎／弓／衝車四兵種，城牆、城門、本陣、林地、丘陵、河川；移動、包夾、火計、混亂、鼓舞、落石、單挑，攻方 20 回合內須攻下本陣
- **單挑**：攻／守／奇的猜拳對決，勇武高者能看穿對手架勢
- **外交**：贈禮、停戰、結盟；一家獨大時諸侯組成「合縱聯軍」
- **存檔**：每月自動存檔＋三個手動檔位（存在瀏覽器 localStorage）

## 原創性

歷史人物、地名與《三國演義》屬公有領域。本作的系統設計（四屬性、軍令、六角格攻城戰、合縱聯軍）、武將數值、水墨地圖與工筆畫像全部為原創，美術均以程式即時繪製，不使用任何既有遊戲的素材、介面或音樂。

## 開發

純 HTML / CSS / JavaScript（ES Modules），不需要建置步驟。

```bash
python3 -m http.server 8080   # 開啟 http://localhost:8080
node tests/sim.mjs 5 60       # 無畫面模擬（局數、月數）：所有勢力交給 AI，檢查規則與平衡
```

| 檔案 | 內容 |
| --- | --- |
| `js/data.js` | 劇本資料：勢力、據點、道路與水路、武將 |
| `js/geo.js` | 地理：海岸、河流、湖泊、山脈 |
| `js/army.js` | 部隊與行軍：出陣、尋路、每月移動、遭遇與戰後處理（不碰畫面） |
| `js/rules.js` | 規則層：內政、經濟、外交、戰後處理、事件（不碰畫面） |
| `js/tactics.js` | 六角格攻城戰、野戰規則與戰場 AI（不碰畫面） |
| `js/battle.js` | 單挑引擎（舊三路陣線戰保留未用） |
| `js/battleui.js` | 戰場操作介面與動畫 |
| `js/inkart.js` | 水墨戰場、部隊棋子 |
| `js/inkmap.js` | 水墨古地圖、標題畫 |
| `js/portrait.js` | 工筆武將畫像 |
| `js/ai.js` | 勢力 AI（內政、出陣、部隊調度、外交） |
| `js/art.js` | 勢力配色、武將畫像快取 |
| `js/ui.js` | 介面與遊戲流程 |
